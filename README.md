# Itinerary Planner ✈️

A minimalist, timeline-centric travel itinerary planner built with Next.js, Tailwind CSS, and Zustand.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fogdev97%2Fitinerary-planner)

## Features

- **Timeline View:** Visualize your trip day-by-day.
- **Budget Tracking:** Real-time cost estimation.
- **Multi-City Support:** Plan complex trips across multiple destinations.
- **Local Persistence:** Data is saved automatically to your browser.
- **Export (Coming Soon):** Generate PDF reports of your trip.

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/ogdev97/itinerary-planner.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Icons:** [Lucide React](https://lucide.dev/)
